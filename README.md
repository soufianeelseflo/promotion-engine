# Promotion Engine

A production-minded portfolio project for **e-commerce promotions, campaign precedence, stackability and checkout simulation**.

## Why this project exists
Discount code forms are easy. Safely operating several overlapping promotions is not. This project focuses on the rules and tooling a merchandising team needs before pushing pricing logic into production.

## Highlights
- Next.js 16 App Router + React 19 + strict TypeScript
- Tailwind CSS 4 using the current PostCSS plugin
- Campaign dashboard with status, attribution and redemption KPIs
- Searchable campaign registry
- Pricing simulation against a sample cart
- Priority + stackability engine
- Minimum-spend and free-shipping behavior
- Conflict detection before publication
- JSON API for campaigns and simulations
- CI for typecheck + production build

## Run locally
```bash
npm install
npm run typecheck
npm run build
npm run dev
```
